Painel de configuração e publicação do site

Instalar Dependências

Instala o Node.js e o Netlify CLI — tudo que é necessário para publicar seu site gratuitamente.

Instalar Tudo
  • Verifica se Node.js está instalado
  • Se não, abre o download automático
  • Instala o Netlify CLI via npm

Deixar o Site Online

Publica o site na Netlify em menos de 1 minuto. Você recebe um link público gratuito para compartilhar.

Publicar Site
  • Faz login na Netlify (grátis)
  • Sobe os arquivos automaticamente
  • Gera um link público para o site

Ou rode manualmente no terminal

Abra o PowerShell ou Prompt de Comando na pasta do projeto e execute:

# 1. Instalar Netlify CLI
npm install -g netlify-cli
# 2. Fazer login
netlify login
# 3. Publicar o site
netlify deploy --dir=. --prod

Crie sua conta gratuita em netlify.com antes de publicar.
